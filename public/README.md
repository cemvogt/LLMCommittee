# Public Assets

This folder contains static assets for the LLM Committee application.

## Required Image

Please save your committee hero image as:
- **Filename**: `committee-hero.png`
- **Location**: This folder (`/public/`)
- **Format**: PNG (or JPG/JPEG - just update the file extension in the code if needed)
- **Recommended size**: At least 1200px wide for best display quality

The image will be displayed on the welcome screen above "Welcome to LLM Committee".
